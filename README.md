# JavaScript Passenger Counter

A simple JavaScript app that counts passengers and saves the count.

## Screenshot

_Screenshot coming soon._

## Features

- **Add** and **subtract** buttons change the count. The count can't go below 0.
- **Reset** sets the count back to 0.
- **Save** shows the current count as "Saved Value is : N".

## Tech stack

HTML, CSS, vanilla JavaScript

## Getting started

```bash
git clone https://github.com/Matiz009/javascript-passenger-counter.git
cd javascript-passenger-counter
# open index.html in a browser
```
